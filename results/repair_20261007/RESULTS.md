# CaPPI 缺失拓扑适配与模态贡献实验

全部 225 个预先冻结的测试评估已完成并通过独立数值及来源核验。核验文件：`D:\1.肝癌\CaPPI_revised\results\repair_20261007\verification.json`。

本轮修改受此前查看的同一基准结果启发，属于适应性复用基准比较；没有新增盲测或独立外部测试集。

各模型使用相同划分、负样本和固定训练图；学习率只由第 0 次重复的验证 BCE 选择，后续重复保持该学习率。检查点取最小验证 BCE，测试分类阈值固定为 0.5。

图随机种子及图嵌入在同一折的全部模型和重复之间固定；3 次种子重复反映神经网络训练随机性，不包含 3 次独立图表示重生成。

先在每次模型种子重复内平均 5 折，再对 3 次重复的均值计算均值与样本 SD。折间 SD 单独保存；训练集重叠的 15 次评估不视为独立样本，未计算显著性 p 值。

AUPR 为 PR 曲线梯形积分；Average Precision 单独保存在 CSV 中，两者没有混用。

protein 划分保证两个端点的蛋白 ID 均与训练分区不重叠，并排除跨分区蛋白对；这不等同于序列同源性独立的泛化评估。仅拓扑模型在该划分的验证/测试端点上没有可用拓扑，其常数预测是预期的可用性对照。

本轮保留既有负样本池。度匹配负样本的基准构造使用完整已知正边网络的度信息，包含留出正边；这些信息不进入训练图、特征或拟合的标准化参数。负样本仍是未观测的候选非相互作用，并非实验确认的非相互作用。完整正边集合也用于数据完整性审查；模型拟合及参数选择不读取测试标签数组或测试分数。

三个融合模型分别检验原路径、加入拓扑屏蔽，以及在屏蔽基础上增加序列旁路；没有单独的无屏蔽旁路模型，不能估计旁路的独立主效应。容量匹配 MLP 未加拓扑屏蔽，修复模型与它的差异同时包含训练方式差异，不能仅据此证明融合机制优越。

MCC 为 0 与单类预测分别检查；AUC/AUPR 的排序表现不能替代固定阈值下的分类质量。

对于常数分数，PR 曲线只有少数阈值点，梯形积分会受约定的 (recall=0, precision=1) 端点影响，可能高于正例比例；这不是有效区分能力。应同时检查 AUC、分数是否恒定及单独保存的 Average Precision。
